# html-css-firefox-clone
A pixel-perfect recreation of the Mozilla Firefox landing page using pure HTML5 and CSS3.

Front-end practice project: Firefox Homepage Clone

A fully responsive (optional, add this if you made it responsive later) static replica of the Firefox landing page. This project was built to sharpen my skills in semantic HTML and advanced CSS layouts, including Flexbox and inline-block positioning, to achieve a clean and modern UI without relying on JavaScript.
